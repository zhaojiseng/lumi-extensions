# 已接入的受限宿主桥接

用户已授权完整受限网关桥接及固定 CLI 入口事务。实现已应用到相邻 main 仓库，保留其原有工作树改动。旧的临时交付补丁已移除，主程序源码为唯一实现来源；两个仓库分别验证、提交与发布。

主程序增加固定网关契约、五类权限、TLS 配对与管理服务、CLI 加密事务、原生恢复入口及 SDK。插件不能获得管理令牌、上游密钥或任意文件路径；iframe 沙箱与禁止直接网络连接的边界保留。

在插件仓库运行：

~~~powershell
npm.cmd run check:gateway-host
~~~

此命令检查实际主程序的完整 TypeScript，并运行网关契约、TLS 管理、配对、CLI 事务和进程探测回归。CLI 使用隔离家目录和假凭据。真实桌面链路与主程序全量验证另见 [验证记录](../../docs/GATEWAY_VALIDATION.md)。

新增可选接口保持扩展 API 1、管理协议 1。首次公开产品版本为 Lumi 1.0.0，模型网关 1.0.0 声明 `minHostVersion: "1.0.0"`；固定宿主与 SDK 随本次发布同步，既有插件保持各自版本。
