# 模型网关（开发目录包）

版本：**1.0.1**。最低宿主为 **Lumi 1.0.1**，扩展 API 为 v1。插件 ID `extension.lumi.gateway` 和既有路由、认证、录制数据保持兼容；升级主程序后，单独安装或替换本插件并重新扫描启用。Lumi 0.5.x 不提供本版所需的全部接口。

运行概况按 **Agent → Lumi → 供应商 → 模型** 展示配置关系，实际请求命中的供应商与可见模型会高亮。一个供应商保存一套 API Base URL、上游认证和协议，其下的多个模型共享这些设置，配置对外名称、实际模型 ID、启用状态，以及是否隐藏于概况。

## 安装与启动

1. 使用本次开发构建的 Lumi EXE。将整个 `extension.lumi.gateway` 文件夹放到 Lumi 的额外插件目录，返回插件设置点击“重新扫描”，启用“模型网关”。更新时替换同 ID 文件夹，保留 Lumi 中已有设置。
2. 插件目录包含 `plugin.json`、`index.html`、`app.js`、`workbench.js`、`style.css`、`README.md` 和完整 `LICENSE`。SDK、默认 UI、网关核心与系统加密由宿主提供，不需要另行安装或启动服务。
3. 首次设置填写供应商 HTTPS Base URL 和上游 API key。接入 API Key 留空时由插件生成，也可在首次 Lumi 设置中指定至少 16 字符的 Key。数据端口与管理端口不同，范围为 1024–65535。
4. 页面打开后自动连接已配置的网关，连接中断时退避重试；未保存的非敏感草稿会保留。完成首次设置后也自动连接。概况中 Lumi 节点的开关负责启动和停止客户端服务，点击 Lumi 节点打开设置。
5. 供应商、模型、上游与接入 Key、网关名称、端口、请求限制、Agent、整流与录制均支持运行中保存。每个请求在接收时固定模型、认证、整流、请求限制与录制策略；新请求使用新配置，已接收的请求继续完成。更换端口时先绑定新入口，再停止旧入口接收新请求；端口占用或提交失败保留原配置和监听。
6. 客户端使用数据端口，管理端口不用于模型请求。CLI 接入保留预览、冲突检查、加密备份和恢复流程。

页面复用 Lumi 默认元素、字体、浅深主题和已有皮肤。供应商和网关弹窗各保留一个外框与一个内容滚动区，内部表单没有额外面板背景、边框或圆角。独立插件不编译进主程序 EXE。

## 四个页面

- **运行概况**：概况面板自动填满剩余窗口空间，保留底部与滚动条旁的间距；顶部保留 OpenAI / Anthropic 两列 Base URL，管理连接、活动请求和录制状态在 Lumi 设置的“运行状态”中查看；网关开关位于 Lumi 节点，供应商、模型列底部的“＋”负责新增，模型可自动从供应商目录获取。Agent—Lumi、Lumi—各供应商、供应商—各可见模型使用同一方式逐一连线；连线在窗口缩放、页面滚动和节点变动后按实际边界重绘。单击供应商打开编辑弹窗；单击模型定位对应编辑行。模型节点与间距已压缩，统计行采用紧凑布局；没有请求的列表、时间线和整流明细不占空间。最近请求、时间线和两处整流入口继续显示真实观测。未知耗时与用量显示“未知”。
- **整流规则**：统一管理服务档位和其他参数，分别编辑入口和模型整流，按供应商、Agent、接口与请求模型匹配，并在本机预览原始请求、入口整流后和实际上游请求。已有档位规则在此读取、编辑和删除，保存继续使用原事务以保留旧匹配语义；新增档位规则使用通用整流。
- **请求记录**：查看实际请求、原始/发送/上游报回档位、用量和经明确同意保存的加密正文，支持分页、筛选、选择、导出与删除。
- **接入与设置**：Codex/Claude Code CLI 接管与恢复、录制开关、保留时长和容量。

供应商的模型列表为空时，带供应商 ID 的旧入口继续按原始模型 ID 转发；统一 Agent 入口只选择明确配置并启用的模型。对外名称可与实际 ID 不同；同名模型存在多个允许目标时明确拒绝，不自动猜测。模型整流的匹配条件使用 Agent 请求中的模型名称。

接入 API Key 统一从概况中的 Lumi 节点进入设置弹窗管理，Agent 无需编辑。新配置自动建立统一接入，使用同一 Key 访问配置的模型；后续新增供应商自动加入这一入口。供应商只编辑自身的上游 API key，接入 Key 不会转发上游。

没有 Agent 的旧多供应商配置继续使用原专属入口和各自 Key，不自动转换认证方式。已有配置里的多个独立接入和授权范围保持，在 Lumi 设置中按“接入入口”选择要更换的 Key；不会合并已有 Key 或扩大旧 Agent 的供应商权限。Lumi 设置提供“自动生成”按钮，通过系统加密随机源生成 32 字节（256 位）密钥并明文显示，可复制；连续生成会更换草稿。生成操作不写认证，仍需“保存接入 API Key”后生效。首次设置同样提供按钮，留空保存继续自动生成。保存成功后在当前 Lumi 设置中显示本次生成的 Key，可复制到 Agent；该显示不进入插件存储、日志或记录。Key 与网关参数独立保存，更换 Key 不应用未保存的端口草稿。

运行中可以生成并保存新 Key；保存后新请求须使用新 Key，进行中的请求保留原认证和模型快照。既有 CLI 接管配置可重新预览和应用。未保存 Key 阻止直接关闭弹窗；取消清空输入，离开页面、断开和主题/上下文变化也清空输入。当前宿主把统一接入凭据存于首条供应商的加密认证中；该供应商需保留，可停用其上游或移除其模型。其他新增供应商可以正常删除。

## 从运行概况配置

- **添加供应商**：点击供应商列表底部的“＋”卡片，填写名称、共用 API 和认证并保存。新增时自动填写可修改的路由 ID 与客户端别名。首次使用时此入口定位到首次设置。
- **添加模型**：点击模型列表底部的“＋”卡片；存在多个供应商时先选择归属，随后自动读取该供应商的模型目录并加入待保存列表。供应商编辑中也可点击“自动获取模型”；目录缺失或认证失败时可手动添加。两个“＋”与节点同宽，高度为 30 像素。
- **编辑与隐藏**：单击供应商，在模型行勾选“隐藏于概况”后保存。隐藏设置保存在宿主提供的插件 `storage` 中，刷新、重连和重新打开页面后保持；“启用”继续控制实际模型可用性。隐藏模型仍保留配置、请求记录和真实请求详情。
- **网关设置**：点击 Lumi 卡片打开设置弹窗，可更换接入 API Key，并设置名称、端口、请求大小与并发限制。首次使用打开初始化表单；运行中可编辑并保存。未保存修改阻止直接关闭，取消恢复保存值。未连接与读取状态中分别显示，不再显示“未确认”。
- **自动目录导入**：添加供应商时填写本次 HTTPS API、协议和 Key 即可获取模型，无需先保存。草稿目录查询只执行受限 GET，不写配置、认证文件、插件存储或推理记录；取消编辑丢弃导入结果。已有供应商使用已保存认证读取目录；修改 API 或协议时必须明确填写本次 Key，不将旧 Key 自动发送到新地址。旧 SDK 不提供草稿查询时明确提示不可用，继续允许已保存供应商读取与手动添加。按实际模型 ID 去重，保留已有别名、启用与隐藏状态，不删除现有模型；名称冲突、目录截断及 128 个模型上限明确提示。目录结果先进入草稿，保存后才生效。编辑 API、关闭弹窗、取消、重连及配置变化会撤回迟到结果。目录 GET 不发送推理请求。
- **网关开关**：开关位于运行概况的 Lumi 节点中，顶部保留实际监听状态与两种接入地址。开启后读取真实监听状态；关闭沿用等待请求完成与确认流程，取消关闭会保留监听。恢复 CLI 入口、取消请求等操作放在“接入与设置”的“高级停止操作”中。
- **保存与取消**：运行中供应商弹窗可编辑并保存。未保存的更改会阻止切换供应商或关闭编辑；“取消编辑”恢复已保存配置。

`storage` 权限保存模型显示偏好与自动接入管理标记，不保存 Key；渲染页面仍不直接读写文件或访问网络。本版新增受限 `gateway.routes.models.preview`，复用 `gateway.config` 权限；已有 detect 与其他 SDK 输入保持兼容。热配置事务由 Lumi 1.0.1 或更新宿主执行，支持小数范围整流规则的持久化解析，设置规则后仍可保存供应商与重启网关。

## 对外接口

配置 Agent 后支持统一入口：

| 用途 | 路径 |
| --- | --- |
| Responses | `POST /v1/responses` |
| Chat Completions | `POST /v1/chat/completions` |
| Anthropic Messages | `POST /v1/messages` |
| 允许的模型目录 | `GET /v1/models` |

OpenAI Base URL 为 `http://127.0.0.1:<数据端口>/v1`；Anthropic Base URL 为 `http://127.0.0.1:<数据端口>`。旧 `/<供应商ID>/v1/...` 路径仍可使用；未配置 Agent 时，裸 `/v1/models` 仅在完整配置恰好一条供应商时兼容。

供应商分别配置允许的入口和实际发送的推理接口。三种原协议支持原始字节转发；跨协议转换覆盖文本、多轮对话、自定义函数工具、工具结果及受支持的图片输入，JSON/SSE 分别转换。不能转换的字段、内置工具、会话状态、隐藏思考、签名、引用等在发送前或响应转换时明确拒绝。

工具默认语义也单独检查：从 Chat/Messages 发往 Responses 时显式保持非 strict 行为；从 Responses 转换工具定义时需要明确的 `strict`，不能把未指定时的自动 schema 处理悄悄改成其他协议的默认值。`strict:true` 不跨到 Messages。模型能力由真实上游决定，目录可见不表示推理、档位或参数受支持。

转换为 Messages SSE 时，为保留真实输入用量及合法消息/内容块顺序，等待上游消息和用量完整后编码输出；首段返回会延后。其他支持的转换可增量输出。缺失观测保持未知，无法满足目标协议所需用量时返回明确转换错误，不补造数据。单事件和完整转换响应分别受 256 KiB/8 MiB 限制。

## 上游接口与错误

供应商的“高级设置 → 上游推理接口”填写该服务实际支持的路径。如果服务只提供 Chat Completions，选择 `/v1/chat/completions`；本地 OpenAI Base URL 仍为 `http://127.0.0.1:<数据端口>/v1`，Responses 入口由网关转换后发送。不要因模型目录可见而假定上游支持 `/v1/responses`。

上游 HTTP 404、429 等非成功响应保留原状态、响应头和正文，不送入成功流转换器，也不通过再次请求其他接口自动重试。上游已经给出明确 `finish_reason` 的 Chat SSE 可在连接正常结束后收尾，保留实际用量与工具信息；仅有内容、keep-alive 或缺失结束原因的 `[DONE]` 仍视为未完成。此兼容行为不代表支持隐藏思考或签名的跨协议转换。

## 两段整流

执行顺序为：**入口整流 → 模型映射与协议转换 → 旧档位规则 → 模型整流 → 上游发送**。所有阶段冻结本次配置。预览只计算，不发送推理请求；输入或配置变化后撤回旧结果。

支持服务档位、推理/思考配置、输出 token 上限、采样、停止条件、工具选择、结构化输出、缓存、存储和元数据等固定字段。动作包括保留、删除、缺失补入、覆盖、按值映射、数值范围限制和拒绝。缺失补入保留显式 null；范围限制遇到缺失字段保持原样，已有非法数值明确拒绝。

同一阶段同一字段按优先级、匹配条件数量、原数组位置选择一条；同一请求中同时命中的父字段与子字段规则明确拒绝。带通配符的内容块缓存路径只允许保留/删除，界面同步限制可选动作。匹配中的供应商和模型可以让供应商公共规则与具体模型规则共用同一引擎。

原始、入口处理后、实际上游发送和上游报回的档位分别展示。自定义值被上游拒绝时保留实际错误，不自动降档、重试或改道。当前路由为固定供应商或唯一模型匹配；故障转移、Gemini、token 计数及 Responses 状态接口仍属于后续阶段。

## 链路、记录和权限

链路由真实运行时的接收、准备、上游开始、上游响应和结束事件构成，最多保留最近 64 项，并显示截断。页面在运行概况可见时读取有版本的快照，重连后可恢复当前进程的最近状态。分别统计进入处理的推理请求、上游尝试、实际整流、改道和返回客户端的处理错误；目录 GET 不计入推理统计，监听前置鉴权/地址拒绝不生成推理记录。

正文默认关闭，需明确同意且系统安全存储可用后才开启。数据仅进入本机记录库，正文不进入应用日志；快照只有有限元数据，正文按段读取。记录截断不表示转发内容被截断。导出仅含脱敏元数据。

清单仍声明 `gateway.control`、`gateway.config`、`gateway.records.read`、`gateway.records.manage`、`gateway.cli-config`，`networkOrigins` 为空。页面保持 sandbox、Node 关闭和直接网络禁止，全部特权操作通过固定 SDK。认证输入提交前、切换页面或断开时清空，不从宿主读取已保存凭据；本次生成的接入 Key 在当前设置中显示并可复制，关闭、取消或上下文变化时清除。

自动生成接入 Key 后立即明文显示，并可复制；保存成功后在当前 Lumi 设置中显示本次生成结果。首次设置留空自动生成也会显示保存后的 Key。关闭设置、取消、切换接入或页面上下文会清除本次显示。

## 概况与请求卡片

供应商与模型区随内容自然展开，统一使用页面滚动；没有 320px 目录高度上限，全部可见模型和连线保留。底部最近请求改为单行小卡片，显示实际模型名称、速率、耗时；历史窗口为这一行能够完整显示的数量，优先展示进行中的请求，完整时间线与整流细节按需展开。

耗时在请求进行中由宿主单调时钟计时，结束后固定为实际记录。速率为最近 **5 秒**实际输出的 Unicode 字符数 / 观测时长，单位明确为 **字符/s**；请求不足 5 秒时按已观测时长计算，结束后冻结最后一个窗口。上游未提供逐段 token 数，字符数不替代 token 数；未取得有效输出观测、编码不支持或旧宿主无窗口能力时显示“未知”。

所有进行中的请求同时着色，总览中的 Agent—Lumi、Lumi—供应商、供应商—模型按实际工作集合高亮。隐藏模型在工作期间临时显示，结束后恢复显示偏好；不会修改存储的隐藏设置。活动请求优先于历史请求保留，避免长请求被后续完成记录挤出快照。

供应商编辑中展示当前配置对应的推理地址预览；不读取或回显凭据。HTTP 404 来源在概况详情和记录详情中明确说明，并展示实际请求使用的上游接口和模型。供应商返回 404 时继续保留原始状态和正文；切换接口须按该供应商真实能力手动选择，不自动付费重试或改道。
