# 工作台便笺

版本：**1.0.1**。最低宿主接口为 API v1，兼容基准为 Lumi 0.5.1；推荐 Lumi 1.0.2。本版修复延迟读取覆盖新输入、保存请求乱序及保存期间继续编辑时的状态提示。

在 Lumi 工作台、侧栏和设置中保存个人便笺。各视图通过 SDK 共享本包的非敏感 JSON 存储，只申请 `storage` 权限，不连接网络。

复制完整目录到 Lumi 的额外插件目录，重新扫描并启用。工作台子开关只撤回卡片，父开关撤回全部贡献。存储有 64 KiB 包级上限，不适合保存密钥或长篇文件。

加载期间可以输入，迟到的读取结果不会覆盖已编辑内容；读取结束后可点击保存。保存按顺序写入，连续点击合并为最后一次明确保存的文本，保存期间的新编辑仍标记为未保存。失败时保留文本并显示错误，可再次保存重试。

验证：在工作台保存便笺，在侧栏读取；停用、重新启用后仍可读取；关闭工作台子开关后其他视图继续可用。宿主最低接口为 API v1，发布基准为 Lumi 0.5.1。
