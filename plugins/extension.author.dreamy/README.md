# 浮梦 · 梦幻界面

Lumi 的独立界面插件，提供粉、蓝、青色背景、半透明磨砂组件与圆角侧栏，支持浅色、深色和跟随系统主题。

## 安装

将整个 `extension.author.dreamy` 目录复制到 Lumi 设置中的额外插件目录，点击“重新扫描”，再在界面插件中选择“浮梦 · 梦幻界面”。支持插件市场的宿主也可直接从市场安装。

保留 `extension.author.dreamy` ID，可沿用已有界面选择。插件仅包含 CSS，没有脚本、数据权限、网络请求、凭据读取或构建依赖；完整 MIT 许可见 `LICENSE`。

## 验证

1.0.3 使用 Lumi 0.5.4 的真实令牌页与本地模拟数据，在 Electron 中检查浅色、深色及 1480×900、1000×900 两种视口。修复前后表头单元格尺寸一致，截图确认各列背景连续；本地记录表头在垂直滚动后保持吸顶，窄视口横向滚动可用。包结构通过固定宿主及 Lumi 0.5.4 校验器。

1.0.2 包结构通过仓库固定的 Lumi v0.5.1 官方校验器和 Lumi 0.5.4 校验器。界面在 Windows、Electron 44.5.0 硬件加速渲染器中使用 Lumi 0.5.4 的真实 React 页面与本地模拟数据检查，覆盖浅色、深色及 1280×900、1080×800 两种视口。

在 1280×900 视口下，设置页的背景模糊节点从 55 个降至 2 个、合成层从 68 层降至 12 层；64 张模型卡片场景的背景模糊节点从 605 个降至 2 个、合成层从 411 层降至 7 层。8 个页面/模式/尺寸场景各重复 3 次、每次滚动 120 帧，渲染线程工作时间平均减少约 24%。两版均保持约 60Hz；这些数值用于比较本地受控场景，不代表所有设备的 CPU/GPU 占用率。

长页面与侧栏弹窗、嵌套弹窗的居中、视口覆盖、焦点恢复和滚动保持，以及原生下拉菜单的尺寸、选项选择和多选筛选操作均已验证。

1.0.1 的历史验证使用 Lumi 0.5.1 开发版本，包含长站点名称和更新状态的 80 组侧栏尺寸组合。
