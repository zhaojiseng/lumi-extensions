# 浮梦 · 梦幻界面

Lumi 的独立界面插件，以液态玻璃风格呈现：柔彩背景、通透侧栏、方向性边缘亮弧与柔和投影，搭配稳定清晰的数据面板，支持浅色、深色和跟随系统主题。

设计参考 [VaJoy《液态玻璃原理及其高性能实现》](https://forum.cocos.org/t/topic/171941)：强调稳定中心、局部边缘折射与内容可读性。插件提供 CSS 玻璃材质，配合增强版宿主在轮廓附近真实扭曲背景，中心与文字保持稳定。

## 玻璃配置与兼容性

启用主题后，在 **设置 → 外观** 调整以下选项；选择由宿主按插件 ID 保存，重启后保留。

| 配置 | 选项 | 默认 |
| --- | --- | --- |
| 玻璃透明度 | 通透、均衡、不透明 | 均衡 |
| 背景模糊度 | 关闭、轻柔、标准、强烈 | 标准 |
| 玻璃扭曲程度 | 关闭、轻微、标准、明显 | 轻微 |

透明度与模糊度独立控制。浮层的模糊半径为 0 / 2 / 12 / 18px；侧栏为 0 / 3 / 18 / 26px；主要功能容器与选中控件使用较浅的 0 / 1 / 3 / 5px，内部行不再叠加模糊。扭曲强度为 0 / 3 / 6 / 10px，作用于宿主支持的侧栏、模型选中状态、趋势浮窗、下拉菜单、公共弹窗与消息提示。模型选中滑块绘制在文字上方，以背景折射形成轻微透镜放大；不对滑块增加模糊，避免文字变糊。点击、拖动及键盘选择仍由下方按钮接收。选择“不透明”、系统减少透明度或强制颜色时，恢复文字在滑块上方，保证可读性。弹窗使用局部折射和半透明底色，全屏遮罩保留模糊渐变；正文始终不应用 filter。

本版本完整效果需要 **Lumi 0.5.13 或更新版本**，其中包含圆角玻璃折射和选中透镜采样。旧版 Lumi 0.5.11 可保留透明度、模糊与玻璃亮边。界面预览使用静态材质。系统要求减少透明度或启用强制颜色时，宿主关闭折射。

## 安装

将整个 `extension.author.dreamy` 目录复制到 Lumi 设置中的额外插件目录，点击“重新扫描”，再在 **设置 → 插件 → 界面风格** 中启用“浮梦 · 梦幻界面”。已启用风格中优先级最高者生效。Lumi 0.5.15 起自定义背景独立叠加，可与浮梦同时启用。支持插件市场的宿主也可直接从市场安装。

保留 `extension.author.dreamy` ID，可沿用已有界面选择。插件仅包含 CSS，没有脚本、数据权限、网络请求、凭据读取或构建依赖；完整 MIT 许可见 `LICENSE`。
