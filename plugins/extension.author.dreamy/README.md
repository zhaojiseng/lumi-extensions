# 浮梦 · 梦幻界面

Lumi 的独立界面插件，提供粉、蓝、青色背景、半透明磨砂组件与圆角侧栏，支持浅色、深色和跟随系统主题。

## 安装

将整个 `extension.author.dreamy` 目录复制到 Lumi 设置中的额外插件目录，点击“重新扫描”，再在界面插件中选择“浮梦 · 梦幻界面”。支持插件市场的宿主也可直接从市场安装。

保留 `extension.author.dreamy` ID，可沿用已有界面选择。插件仅包含 CSS，没有脚本、数据权限、网络请求、凭据读取或构建依赖；完整 MIT 许可见 `LICENSE`。

## 1.0.1

- 增强背景色彩变化、透明度与磨砂效果，统一常用组件的表面样式。
- 主体使用固定圆角框架，内容在框架内滚动，上下保留模糊边缘。
- 修复长页面弹窗定位及打开时的滚动问题。
- 修复接口地址、更新提示圆角，使下拉选项与原控件宽高一致。
- 统一导航、设置、更新提示和站点切换行的左右边界。

窗口原生亚克力及浮窗、托盘圆角由 Lumi 宿主提供，插件包中的 CSS 用于主界面。

## 验证

包结构使用仓库固定的 Lumi v0.5.1 官方校验器验证。界面在 Lumi 0.5.1 开发版本的真实 React 组件与 Electron 渲染器中检查：包含浅色、深色、常规和窄窗口、长站点名称以及更新状态的 80 组侧栏尺寸组合，均与导航左右对齐；弹窗居中、内容滚动、下拉选项尺寸与选择操作也已验证。

从仓库根目录运行 `npm run check -- plugins/extension.author.dreamy`。直接安装，无需构建。
