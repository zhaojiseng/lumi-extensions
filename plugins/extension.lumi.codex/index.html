    Codex 对话

    Lumi 只是显示层：对话、工具调用与审批全部交给本机 codex app-server，主程序只做受白名单约束的 JSON-RPC 隧道。

    项目说明
    权限codex.bridge（受限隧道，仅对话相关方法）
    数据流插件 ↔ 主进程 ↔ codex app-server（stdio JSON-RPC）
    沙箱 / 审批完全由 Codex 自身配置决定；本插件不自动审批
    凭据由 Codex CLI 管理，插件不读取也不保存
    可用方法initialize、thread/*、turn/*、model/list、skills/list、account/read
    被拒绝process/*、command/exec、thread/shellCommand、fs/*、account 写入 等

    需要 Lumi 0.5.16 或更新版本。离开对话页会关闭连接并终止在途任务；再次打开可恢复历史会话。
